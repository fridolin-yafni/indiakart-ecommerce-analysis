# IndiaKart E-Commerce Analytics

An end-to-end analytics project on two years of IndiaKart marketplace data
(24 Jun 2023 – 23 Jun 2025): 50,000 orders, 100,000 order items,
10,000 customers and 10,000 return requests.

## What I did
- **Data cleaning (Python, pandas):** removed duplicates and formatting issues,
  standardised dates, and added flags for later analysis.
- **Exploratory analysis (matplotlib):** 10 charts covering order volume, revenue,
  categories, order status, states, customer segments, payment methods,
  customer age, return reasons and average order value.
- **KPIs:** GMV, average order value, cancellation rate and return rate.
- **Dashboard (Power BI + DAX):** 5 pages – Revenue Overview, Category Performance,
  Customer Insights, Operations and Inventory Alert – with slicers and key insights.
- **Management report:** a plain-language summary for the CEO with findings,
  risks, opportunities and recommendations.

## Key findings
- Sales are steady at about 2,100 orders a month, with no Diwali boost.
- Electronics brings in about 57.6% of revenue.
- About 12% of orders are cancelled, above the 10% target.
